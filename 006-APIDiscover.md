
Aller vers "API Manager",       
Cliquer sur API Instances, cliquer sur le button "Add" et choisir "Add New API",     
Les options selectionnés:     
1- Mule Gateway    
2- Connect to existing application (basic endpoint)    
3- Mile 4 (recommended)    
4- cliquer sur Next.    
5- Choisir l'API From Exchange, et selectionner l'api 'sf-case-api'    
Next, Next et "Save" 

Prendre le numéro de l'API , qui va etre le api.no utilisé par l'autodiscovery.
